CodePapr — 本地优先的编码 Agent 运行时

Tauri 桌面工作台 + CLI，都以 JSON-RPC 客户端的形式说话同一个本地 codepapr-server 宿主。主 Agent 调度 Explore/Scout/Mentor 三个内置子代理，支持自定义扩展；文件、Git、Shell、LSP 全在本地完成。

查看架构 系统架构深入 阅读教程

架构：宿主守护进程 + 瘦客户端

CodePapr 不是单体 Tauri 应用。Rust 领域逻辑住在共享库 crate codepapr-core，由独立的 codepapr-server 守护进程对外服务，桌面端与 CLI 都只是行分隔 JSON-RPC （TCP 127.0.0.1 或 stdio）的调用方。

桌面客户端 (codepapr)      codepapr-cli
        │  JSON-RPC · TCP/stdio │
        └─────────┬─────────────┘
                    ▼
     codepapr-server — handler.rs → 159 个 RPC 方法
                    ▼
     codepapr-core — fs·git·shell·lsp·db·snapshot·mcp·web·agent

桌面端只保留 GUI 专属能力（codepapr-app:// 协议、内置/无头浏览器、TTS、Stronghold 密钥保险箱、App 安装与端口探测），其余全部是 src-tauri/src/commands.rs 里的 RPC 代理。完整拓扑、RPC 面、数据流与持久化所有权 → 系统架构页。

四种工作模式

模式适合行为
Ask解释、分析、建议只读—不改文件不跑命令
Plan复杂任务拆解先出方案，确认后执行
AgentBug 修复、功能实现自主执行：搜索→修改→验证
App数据可视化、探索即时生成交互式应用，渲染 D3/ECharts/Mermaid

核心能力

宿主/客户端拆分

桌面、CLI 与未来客户端都说 JSON-RPC 说同一个本地 codepapr-server。

多 Agent 协作

主 Agent 通过 task 工具调度 Explore/Scout/Mentor 及自定义子代理。

TodoList 任务规划

自动创建并跟踪任务清单，进度汇报与重规划。

项目记忆（零审核）

偏好、约束、已验证事实自动存入 SQLite 账本，面板是唯一人工面。

代码智能 LSP+AST

9 个导航 action，LSP 优先自动降级 AST 项目图（带 source/confidence）。

LLM 前缀缓存

三层提示词注入策略，最大化缓存命中。

MCP 协议支持

stdio/SSE/Streamable HTTP，MCP 市场一键安装，逐服务器权限模式。

深度 Git 集成

8 个 Git action + diff 面板 + 安全回退（备份引用+撤销）。

App / 插件市场

.papr 应用从官方注册表安装，每个应用有自己的 origin、CSP 与 SQLite 存储。

GLOBAL

~/.codepapr/apps/<appId>/

跨项目通用工具。

WORKSPACE

<workspace>/.CodePapr/apps/<appId>/

项目专属，可随仓库分发；同 appId 时覆盖全局安装。

权限是两轴模型—本地访问 × 网络，全局默认加逐应用覆盖，在“设置 → App”里配。详见系统架构 · App 市场与作用域。
