CodePapr 桌面工作台
四种工作方式

同一个 Runtime，四种模式

Ask · Plan · Agent · App —— 同一个 Runtime，从解释到执行再到 .papr 应用

Ask

解释架构、梳理职责、分析报错原因。默认不改文件、不跑命令。先问清楚，再决定是否执行。

只读 · 解释

Plan

大改动前先出方案、任务清单与验证路径；可用 question 澄清歧义，确认后再落地。

规划 · 拆解

Agent

完全自主执行：搜索项目、读写文件、跑命令、做验证。修复 Bug、实现功能一步到位。

执行 · 读写

App

生成交互式 .papr 应用（图表、看板、面板），也可从官方市场安装到全局或项目作用域，独立 origin / CSP / SQLite。

可视化 · 市场安装
桌面工作台

不只是聊天窗口

文件树 · Monaco · Git · 浏览器 · LSP · 插件市场 — 全在一个界面

项目文件树 + LSP

完整的项目浏览，Monaco 高亮，LSP 优先（定义/引用/hover/调用层级），不可用时自动降级 AST 项目图。

斜杠命令面板

输入 / 列出命令，键盘导航。

Agent 自主执行

自动搜索 + 读写 + 跑命令 + 验证。Agent 循环在桌面端 @codepapr/core，副作用经本地宿主执行，界面保持流畅。

Git 深度集成

Diff、提交、分支切换、安全回退。Agent 负责分析，人工保留高风险操作。

浏览器联动

启动预览、页面交互、截图。前端联调在一个窗口里闭环。

TodoList 任务规划

复杂任务自动创建清单，实时跟踪进度，完成后自动折叠。失败自动重试。

Goal 自主循环

/goal：主 Agent 执行，Verifier 验收，直到验证条件通过。

对话重置（Git）

每条用户消息前自动 commit。消息上可 reset --hard，代码和对话一起回退。

对话轮次导航

右侧轮次条，点击跳转到对应轮。

项目记忆（零审核）

偏好、约束与已验证事实自动写入 SQLite 账本；面板是唯一给人看的面。短指令进 Bootstrap，踩坑经验按回合 Recall，网页引用只进搜索。上下文怎么拼。

App / 插件市场

从官方注册表安装 .papr 到全局或项目；独立 origin、CSP 与私有 SQLite，支持 app_publish 推送。

多 Agent 协作

主 Agent 经 task 调度 Explore（代码）、Scout（网页）、Mentor（架构）；另有 Verifier / Compactor。

桌面 + CLI 宿主

桌面与 codepapr-cli 共用本地 codepapr-server（JSON-RPC）。领域能力在 codepapr-core，客户端只做瘦调用方。教程

角色扮演 实验

创建或导入角色卡（PNG/JSON）。激活后按该角色口吻对话。默认关闭，在 设置 → 通用 → 实验性功能 开启。

本地语音合成（TTS） 实验

基于 GPT-SoVITS，几秒参考音频即可克隆声音。支持流式合成与多语言。默认关闭，在 设置 → 通用 → 实验性功能 开启。

内置命令

输入 / 即可调用

19 个内置命令，按任务复杂度自动路由到主模型或快速模型；/help /commands /undo 不走模型，零 Token 消耗

命令用途模型
/help   /commands列出所有可用命令及说明本地
/compact强制压缩当前会话上下文（v4 确定性骨架检查点；仅超预算时一次二级摘要）主 / 快速
/undo撤销上一次对话重置（恢复被截断的对话与代码快照）本地
/goal自主循环：主 Agent 执行 + Verifier 验收，直到验证条件通过主模型
/review审查改动或指定范围，优先报告 bug 和回归风险主模型
/fix定位并修复问题，自动运行验证主模型
/test为指定功能补测试或运行已有测试主模型
/explain解释文件、函数、符号或错误实现思路主模型
/diagnose诊断报错、慢操作或异常行为根因主模型
/refactor保持行为不变的安全重构主模型
/doc编写或更新文档（仅 .md 扩展名）主模型
/new根据描述从零创建新文件、组件或功能主模型
/optimize分析并修复性能瓶颈，降低复杂度或资源消耗主模型
/build构建项目并诊断/修复构建错误主模型
/search搜索代码库中的模式、用法、定义或引用快速模型
/lint运行 linter 并修复违规快速模型
/clean清理死代码、未用导入和遗留调试语句快速模型
/commit暂存改动并生成规范的 commit message快速模型
/summary对文件、模块或整个项目做高层概述快速模型
💡 支持在 .CodePapr/commands/<name>.md 或项目配置中自定义斜杠命令，支持 $ARGUMENTS 参数、@path 文件嵌入与 !`cmd` 内联命令。查看自定义教程 →
