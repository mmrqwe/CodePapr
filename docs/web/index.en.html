CodePapr — a local-first coding agent runtime

A Tauri desktop workbench and a CLI, both speaking JSON-RPC to the same local codepapr-server host. The main agent dispatches the Explore/Scout/Mentor sub-agents and supports custom extensions; file I/O, Git, shell, and LSP all run locally.

Architecture: a host daemon plus thin clients

CodePapr is not a monolithic Tauri app. Rust domain logic lives in the shared crate codepapr-core, served by the standalone codepapr-server daemon; the desktop app and CLI are both line-delimited JSON-RPC callers (TCP 127.0.0.1 or stdio).

Desktop client (codepapr)      codepapr-cli
        │   JSON-RPC · TCP/stdio  │
        └──────────┬──────────────┘
                    ▼
     codepapr-server — handler.rs → 159 RPC methods
                    ▼
     codepapr-core — fs·git·shell·lsp·db·snapshot·mcp·web·agent

The desktop client keeps only GUI-only capabilities (codepapr-app:// protocol, embedded/headless browser, TTS, Stronghold vault, app install and port probing); everything else is an RPC proxy in src-tauri/src/commands.rs. Core capabilities

Host-client split

Desktop, CLI, and future clients all speak JSON-RPC to the same local codepapr-server.

Multi-agent collaboration

The main agent dispatches Explore/Scout/Mentor and custom sub-agents via the task tool.

TodoList planning

Agents auto-create and track task lists with progress reporting and re-planning.

Project memory

Preferences and verified facts save automatically to a SQLite ledger; the panel is the only human surface.

Code intelligence

9 LSP navigation actions, LSP-first with automatic AST project-graph fallback (source/confidence tagged).

LLM prefix cache

Three-layer prompt injection strategy to maximize cache hits.

MCP protocol support

stdio / SSE / Streamable HTTP; one-click MCP marketplace install; per-server permission modes.

Deep Git integration

8 Git actions + diff panel + safe rollback with backup ref and undo.

App / plugin marketplace

.papr apps install from the official registry; each app gets its own origin, CSP, and SQLite storage.

GLOBAL

~/.codepapr/apps/<appId>/

Cross-project tools.

WORKSPACE

<workspace>/.CodePapr/apps/<appId>/

Project-specific, shippable with the repo; overrides the global install on a matching appId.

Permissions are a two-axis model — local access × network — with global defaults plus per-app overrides under Settings → App. See System architecture · App marketplace and scope.
