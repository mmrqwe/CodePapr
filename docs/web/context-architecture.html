一次请求 · 从上到下

上下文怎么拼，记忆进哪一层

发给模型的不是一锅炖。越靠前的内容越稳，前缀缓存越好用。项目记忆按该进哪层就进哪层：短指令每次带着，踩坑经验这一轮再用，网页引用只等人去搜。

一次请求长什么样

从上到下读。上面尽量不动，下面才增长。颜色表示变化快慢，不是重要程度。

01

系统核心

系统提示、工具定义、模型参数、AGENTS.md

会话内冻结
02

会话引导

Skills 目录、项目记忆段、长期指导

记忆：压缩或新会话才换
03

会话状态

检查点（这一场任务进行到哪）+ 保留的近期对话

压缩时重写
04

本回合召回

这一轮可能用得上的旧经验，插在当前用户消息前

每个用户回合换新
05

本轮对话

当前用户消息、本轮工具结果；日期等动态内容也在这里

只往尾部追加

分层各管什么

五段请求，四个变化节奏。同一条信息只应出现在其中一层。检查点是这场任务的进度，不是跨会话项目记忆。

STABLE PREFIX

稳定前缀 · 01 + 02

  • 装什么：身份与工具边界、AGENTS.md、Skills 名称+一句话、每次会话带着的短记忆、你设的长期指导。
  • 何时变：你改规则、技能或参数，会重建前缀。新记住的内容不拆当前前缀，等压缩或下次会话。
  • 预算：项目记忆段最多 24 条 / 1500 tokens。Skills 全文用 skill_load 按需读，不进前缀。
SESSION STATE

会话状态 · 03

  • 装什么：压缩后的检查点（目标、待办、已确认事实）和还没被折进去的近期对话。
  • 何时变：轮数或长度超限、或你执行 /compact。接受一次失效，换可控的上下文。
  • 不装什么：不要把待办抄进项目记忆。检查点随这一场任务死，记忆跨会话活。
TURN RECALL

回合召回 · 04

  • 装什么：这一轮检索命中的旧经验，主要是踩坑记录。最多约 5 条 / 1200 tokens。
  • 何时变：每个用户回合重新检索一次。只活在这一次请求里，不写进对话历史。
  • 不装什么：网页 / MCP 引用不自动召回，避免把外部文字当成指令。
ACTIVE TAIL

活动上下文 · 05

  • 装什么：当前用户消息、本轮工具调用和结果。大段输出落盘，用 read_artifact 回看。
  • 何时变：每一轮只在尾部追加。这是缓存 miss 里唯一「本来就该有」的增量。
  • 不装什么：日期、时区、诊断不进前缀，免得每分钟拆缓存。

一条记忆怎么走

权威在 SQLite 账本。记忆面板是唯一给人看、改、遗忘的面。没有独立的记忆文件。

1 · 来源

谁提出

你说「记住 / 必须 / 不要」、测试跑通、冷启动摘要、Agent memory_write、或你在面板手写。

2 · 门

留下或丢掉

确定性规则立刻决定：正常事实留下，注入 / 密钥 / 危险命令丢掉。没有「请你点同意」。

3 · 账本

面板立刻可见

留下的进入 memory_entries。同内容会覆盖旧条。当前会话前缀这时还不变。

4 · 去向

按种类进层

短指令等压缩或下次会话进前缀；踩坑下一回合可召回；网页引用只出现在搜索里。

每次会话

进 02 会话引导

手写笔记、偏好、约束、项目事实、约定、验证、决策。最多 24 条 / 1500 tokens。

面板分组：每次会话
按需召回

进 04 本回合召回

踩坑经验 procedure。写入后的下一用户回合，检索命中才出现。不进每次会话的前缀。

面板分组：按需召回
仅搜索

不自动进请求

网页 / MCP 引用 citation。模型调用 memory_search 才会看到。永不进 02，也不自动召回。

面板分组：仅搜索

AGENTS.md 是你写的项目规则，改了会重建前缀。项目记忆是自动积累的事实与偏好，新写入不拆当前前缀。检查点是这一场任务进行到哪。三者不要互相复制。

模型怎么读到记忆

不会把账本整库塞进请求。读取只有三条路：已经带着、系统按这句话搜、Agent 自己调工具。

不用工具

已经在 02

每次会话带着的短指令，Agent 张口就能看到。新写入要等压缩或下次会话，不会为了多看几条去拆当前前缀。

不用工具

系统按这句话召回

每个用户回合（Ask 除外）用你这句话做关键词匹配，命中的踩坑经验插进 04。最多约 5 条 / 1200 tokens。citation 和不可信内容跳过。查询太短或预算不够，本回合就不召回——不是把全部记忆倒进去。

用工具

Agent 主动搜

自动召回不够时，Agent 调用 memory_search。这是搜 citation 的唯一路径。结果出现在工具返回里，并可以再插一条召回块给本回合后续请求（每回合最多一次）。

memory_search

按关键词检索账本 + 历史检查点。可限定类别。Ask 模式也能用。这是「主动读记忆」的主工具。

memory_review_candidates

列出目录，最多 40 条预览。只有 Agent 主动调才会跑；不是每回合自动全表扫描。Ask 模式不可用。

memory_write / memory_forget

写入或遗忘。手写笔记不能用工具删。Ask 模式不可用。

skill_load

按需读某个 Skill 全文。02 里只有名称 + 一句话，Skills 不是账本记忆。

系统提示会教 Agent 用 memory_write 记下该记的东西；memory_search 作为工具一直挂着，需要时再调，不会每句话先搜一遍。

三种时钟

同一条记忆落库之后，什么时候真正出现在模型眼前，取决于你现在处在哪一拍。

本回合

账本和面板立刻更新。当前前缀不动。如果是踩坑经验，要等到下一个用户回合才可能被召回。

压缩

检查点重写（任务进度）。同时从账本重渲染项目记忆，短指令这才进入稳定前缀。

新会话

总是从账本重渲染会话引导。若账本还是空的、且有项目图，后台写一条结构 / 技术栈摘要，下次或压缩后进入前缀。
